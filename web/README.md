# Ottera Web Prototype

React + Vite scaffold for the Ottera PearlHacks web experience.

## Run locally

1. `cd web`
2. `npm install`
3. `npm run dev`

## Notes

- Primary header matches requested layout: logo left, Home/Find Resources/About Us center, auth/user on right.
- Public users can browse resources but cannot subscribe/message without logging in.
- Includes demo portal states for Admin, User, Volunteer, and Distributor.
- Add your real logo at `public/logo.png`.
