# Ottera🦦
Ottera is a community-focused site where users facing financial hardship can find resources they need, such as food, clothing, shelter, and free community events happening in their city.

## Table of Contents
- Features
- Screenshots/Demo
- Installation
- Usage
- Tech Stack

## Features
- Browse clothing being donated by the community
- Find pantries near you
- Search for nearby shelters
- Subscribe to local non-profits for updates on events, pantries, etc.
- communicate with non-profits through our chat feature
- Utilize Google Gemini to make the search for food, clothes, and shelter easier

## Installation
 - Install Node.js and npm
 - Clone the repository
 - Install dependencies
 - Create a '.env.local'file in the root directory and add the following:
  NEXT_PUBLIC_SUPABASE_URL=your-url-here
  NEXT_PUBLIC_SUPABASE_ANON_KEY=your-key-here
- Run the development Server
   
## Usage
- Sign up or log in to gain access to your profile
- Sign your non-profit up with the "partner with us" tab
- Users can sign up to be a simple user or a volunteer
- Click "find resources" to browse through the different categories
- Subscribe to non-profits by clicking a post with that non-profit
- message non-profits or sellers through our chat service
